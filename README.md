
# Aula — Consumo de API Web

Este repositório contém o código utilizado na aula sobre **consumo de APIs Web com JavaScript**.

## Objetivo da atividade

Complete o código JavaScript para que os campos **Bairro**, **Cidade** e **Estado** sejam preenchidos automaticamente utilizando os dados retornados pela API.

## Passo a passo

1. Faça um **fork** deste repositório para a sua conta do GitHub.

2. Faça o **clone** do repositório para o seu computador.
    
    2.1 git clone URL_REPOSITORIO

3. Abra a pasta do projeto no **Visual Studio Code (VS Code)**.

4. Verifique se a extensão **Live Server** está instalada no VS Code.

   4.1 Você pode instalar a extensão por meio do link abaixo:

   https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer

   4.2 Ou, procure por Live Server do autor Ritwick Dey na aba extensão do VS Code.

5. Localize o arquivo `index.html`.

6. Clique com o botão direito sobre o arquivo `index.html` e selecione a opção:

   **Open with Live Server**

7. Com a página aberta no navegador, complete o código JavaScript para que os campos abaixo sejam preenchidos automaticamente com os dados retornados pela API:

   - Bairro
   - Cidade
   - Estado

 **Resultado esperado**

Após informar um CEP válido, a aplicação deverá consultar a API e preencher automaticamente os campos de endereço com as informações recebidas.

8. Faça commit das mudanças

    8.1 git add .
    8.2 git commit -m "sua mensagem"
    8.3 git push origin main

9. Envie seu repositório para o professor no class.
